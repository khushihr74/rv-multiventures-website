# RV Multiventures Website

Premium multi-business corporate website built with Next.js 14, React and TypeScript.

## Brand direction
- Brand: RV Multiventures
- Suggested tagline: Diversified Businesses. Lasting Impact.
- Visual identity: deep navy, champagne gold and warm white.
- Suggested domain candidates to check: `rv-multiventures.in`, `rvmultiventures.in`, `rv-multiventures.com`. Availability and trademark clearance are not yet verified.

## Run locally
1. Install Node.js 20 or newer: https://nodejs.org/
2. Extract this ZIP.
3. Open a terminal in the project folder.
4. Run `npm install`
5. Run `npm run dev`
6. Open http://localhost:3000

## Before public launch
- Choose and register an available domain; then update `metadataBase` in `app/layout.tsx` and the sitemap/robots domain.
- Replace contact placeholders with verified phone, email and addresses.
- Add approved original business photographs and social links.
- Verify business descriptions, legal registrations and service claims.
- Connect a secure form backend before accepting live enquiries; the starter contact form currently opens an email app and does not store submissions.
- Complete and review privacy policy and terms.
- Test all pages on mobile and desktop.

## Deploy to Vercel
1. Push this project to a GitHub repository.
2. Import the repository at https://vercel.com/.
3. Keep the detected Next.js settings and deploy.
4. Add the registered domain in Vercel project settings and follow the displayed DNS instructions at your registrar.

No domain, hosting account, email, phone number, registration, testimonials, or social account has been fabricated.
